One row per task. Newest at the top. Status is `planned`, `in-progress`, `done`, or `abandoned`. The convention is in [`claude/rules/worklog.md`](../claude/rules/worklog.md).

To start an entry: copy `_template/` to `YYYY-MM-DD-short-slug/`, fill in `plan.md`, and add a row here.

**Let the summary run long.** This file is the only artifact that survives every compaction, so write the row you would want to find in three months with no memory of the work.

The first four rows are backfilled. The work was done before the convention existed and the `plan.md` files say so; the `errors.md` files beside them are accurate, because those incidents are what the harness was built from.
